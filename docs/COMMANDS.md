# Tangler command reference

Generated from feature declarations and the shared localization resources in `Sources/CoreKit/Resources`. Do not edit this file by hand; run `scripts/update-commands.sh` in the development repository after changes.

Hold the configured leader key (right Command by default), then enter a leader sequence. Global shortcuts work independently. Digit placeholders select the numbered target. These are declaration defaults; user settings may override them.
